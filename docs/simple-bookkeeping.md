# 手机公私账简易入口

这一版将手机首页的主要操作改为“公账 / 生意的钱”和“私账 / 个人的钱”。同一个微信、银行卡或现金账户可以同时有两类流水，归属按每一笔交易保存，不按账户推断。

本版新增入口与说明采用中文，针对中文手机用户；上游其他语言界面及原有翻译仍保留，但新增文案尚未加入多语言词典。

## 使用

1. 在手机首页点击“启用公账 / 私账记账”，确认后会创建两个专用标签：`账本：公账`、`账本：私账`。已有同名标签会复用，不创建重复标签。若重名不唯一则要求用户检查标签设置。
2. 点公账或私账，再点记收入或记支出。填写金额、分类、账户后，核对顶部归属并点大号“保存这笔账”。也可以在编辑页切换归属。
3. 首页分别查看公账、私账流水。未归类旧账和同时带两个标签的冲突流水有单独入口。列表始终显示归属，即使普通标签显示被关闭。
4. 手机新增或编辑收入、支出、转账时，保存前必须明确选择一个归属。原有其他标签保留；草稿、模板或识别功能带来两种标签时，必须先通过大按钮纠正才能保存。已有交易打开时不会改动其账户或归属。
5. 原首页图表折叠在“更多功能：全部账户统计”中，明确包含所有公账、私账及未归类账户，不将其伪装成某一本账的统计。

## 数据与边界

- 使用原有交易标签 API，不修改数据库结构，不迁移或重写旧数据，不读取本机账本或密钥。
- 归属随服务端交易和标签同步，不使用本机浏览器映射。
- 归属是管理分类，不是独立余额账户，不把同一银行卡虚构成两个资产余额。跨账户转账仍按原资金账户处理。
- 专用标签应保留名称；删除或重命名会使相应流水成为未归类。可在标签设置中恢复原标签名称。重新创建被删除的标签会获得新 ID，不会自动找回旧关联。
- 这一版主要覆盖手机手动记账和手机流水查看。桌面、导入、API 和外部客户端仍使用原有标签功能，可能产生未归类或冲突流水；可在手机检查并逐笔补选。不是服务端强制账本隔离。
- 同名标签已用于旧数据时，启用会按该标签现有含义显示这些流水，请先核对；不会批量改变任何旧流水。
